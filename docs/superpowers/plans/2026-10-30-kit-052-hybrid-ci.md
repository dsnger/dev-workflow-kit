`docs/superpowers/stories/2026-10-30-kit-052-hybrid-ci-story.md` (level 2) · **Gate A:** runs (risk high)

Execution: subagent-free, in this session, task by task, a WIP commit after each task (`git commit -m 'WIP: …'`).
Each task ends with its own suite green. Every full battery run goes through `sh scripts/local-ci.sh <head>` on
a pushed branch head (never the raw quality command), so it holds the machine-wide heavy lock T2 builds and
posts `quality` on that head (long runs below).

## Long runs (≥ 15 min, each needs the orchestrator's go)

| Run | Proves | Estimate | Runs | Limit / cleanup |
|---|---|---|---|---|
| `sh scripts/local-ci.sh <pushed WIP head>` before Gate B pass 1 | battery green before Gate B; lock taken in real use | ~35 min | 1 | see below |
| `sh scripts/local-ci.sh <head>` after a repair that touches scripts | battery green on the repaired head | ~35 min | 0–1 | see below |
| `sh scripts/local-ci.sh <final head>` | `quality` on the PR head (Actions disabled until 1 Nov) | ~35 min | 1 | see below |

**Limits and cleanup.** Each run starts with `HEAVY_LOCK_WAIT_SECS=3600` (the lock wait is bounded apart from
the battery) and runs as a background Bash task. Battery time limit: 60 min from the moment the lock note names
this run's holder. On the limit, the holder (its pid is the note's first line) gets INT: its handler stops the
battery's process group (TERM, KILL after 5 s), reaps it, then exits, releasing the lock; `local-ci.sh` then
exits 130 and removes its worktree. If the removal fails the script prints `git worktree remove --force '<path>'`
and I run exactly that. Never a KILL to the holder first (it would release the lock with the battery still
running). The suites' own temp directories are removed by their EXIT traps; a run cut off by the limit is
followed by `ps -o pid,pgid,command` for leftover `local-ci`/suite processes, stopped by group.

**Failures in one run.** The chained `&&` stops at the first red stage, so one run does not show every failure.
On a red, the failing stage is fixed and rerun alone, then every remaining stage of the row runs once
separately (each a few minutes; the two hook suites the longest), all results recorded, before the next full
`local-ci.sh` run.

**Budget.** Planned: 2 full runs (70 min), allowance 3 (105 min) under the 2-hour unit limit. A fourth would
pass it: then the handover boundary moves to the close of the running Gate B cycle (never inside it), and the
rest continues in a fresh session.
